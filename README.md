## About Me

I'm a Computer Science and Neuroscience student at Auburn University focused on
**C++23, low-latency systems, Linux, concurrency, algorithms, and performance engineering**.

I enjoy building systems where implementation details directly affect performance and correctness.
My current work centers on low-level C++ projects including an **in-memory limit order book and exchange simulator**
with price-time priority matching, deterministic processing, and performance benchmarking.

I also work on Linux systems and networking through a **multithreaded HTTP/1.1 server**
using non-blocking sockets, `epoll`, worker threads, and lock-free queueing.

Outside of personal systems work, I contributed to **Google Summer of Code 2024** with INCF/NetPyNE,
where I optimized neural simulation tooling from roughly **2.0s to 0.5s per run**,
reducing runtime by **75%** and enabling **4× faster experimental iteration**.

My main interests are:

- Low-latency and performance-critical C++
- Trading systems and market infrastructure
- Linux systems programming
- Concurrency and synchronization
- Networking and event-driven systems
- Algorithms and competitive programming
- Performance measurement and profiling

## Featured Projects

### Ultra-Low-Latency Limit Order Book Simulator & Backtester
**C++23**

- In-memory exchange simulator with **price-time priority**
- Deterministic order processing with nanosecond-resolution timestamps
- Supports insertion, cancellation, modification, partial fills, and matching
- Sustained **3.58M backtest simulation steps/sec**
- Approximately **279 ns/step**
- Tracks PnL, drawdown, Sharpe ratio, and execution statistics

[View Repository](https://github.com/Jsprouse0/ULL-Limit-Order-Book)

---

### High-Performance Multi-Threaded HTTP Server
**C++23 · Linux**

- Event-driven HTTP/1.1 server using non-blocking sockets and `epoll`
- Worker thread pool for request processing
- Lock-free MPMC queue architecture
- Benchmarking focused on throughput, p50/p95/p99 latency, CPU usage, and context switches

[View Repository](https://github.com/Jsprouse0/Multi-Threaded-Web-Server)
